# CHOPR Publications Database

A searchable database of publications produced by the Center for Health Outcomes and Policy Research (CHOPR).

## Metadata Fields

- Title
- Authors
- Publication Year
- Journal
- DOI
- PubMed URL
- Topics
- Data Sources
- Project/Study
- State(s)
- PDF Link
- Notes

## Planned Features

- Search by keyword
- Filter by topic
- Filter by data source
- Filter by year
- Filter by project
- AI-assisted search
